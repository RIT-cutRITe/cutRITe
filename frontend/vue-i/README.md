# vue-i

## How it was made
Using
```
    yarn create vue
```

The options selected were:
- Typescript
- JSX Support
- Router for SPA development
- Vitest
- Cypress for End-to-end testing

## Running
After moving into this folder, run
```
    yarn
```
to install all required packages and then
```
    yarn run dev
```
to start locally. Otherwise it is run along with the server in the docker compose at the top level of this repo.
